# Ecommerce Detail Page Skill

## 目标

本 skill 用于支持淘宝、天猫、拼多多、小红书、抖音电商等平台的商品详情页策划、主图设计、卖点文案、图片提示词和转化率优化。

重点适配毛绒玩具、棉花娃娃、IP公仔、挂件、抱枕、潮玩周边、礼品类产品。

## 适用场景

- 淘宝详情页6张图方案
- 商品主图5张规划
- 小红书商品图文种草
- 毛绒玩具详情页卖点提炼
- 棉花娃娃详情页结构
- AI商业摄影提示词
- 详情页标题、副标题、卖点文案
- 产品规格、材质、尺寸、工艺说明
- 爆款视觉风格规划
- 竞品详情页拆解与优化

## 输入材料

优先提供：

1. 产品图片或AI效果图
2. 产品名称
3. 产品类型
4. 目标用户
5. 售价区间
6. 尺寸和材质
7. 核心卖点
8. 平台，例如淘宝、小红书、拼多多、抖音
9. 风格要求，例如高级商业摄影、可爱治愈、国潮、潮牌、礼物感
10. 需要输出的图片数量，例如主图5张、详情页6张、详情页10屏

## 默认输出内容

回答时优先输出：

1. 产品定位
2. 目标用户
3. 核心卖点
4. 主图方案
5. 详情页分屏脚本
6. 每张图的画面构图
7. 每张图的主标题、副标题、卖点文案
8. AI绘图/摄影提示词
9. 详情页排版建议
10. 转化率优化建议
11. 适合小红书/淘宝搜索关键词
12. 注意事项

## 淘宝详情页6张图标准结构

### 第1张：首屏爆款主视觉

目标：3秒吸引点击和停留。

内容包括：

- 产品完整正面大图
- 高级背景或生活场景
- 核心卖点大标题
- 1句情绪价值文案
- 品类标签，例如治愈系毛绒公仔、生日礼物、桌面陪伴

### 第2张：核心卖点拆解

目标：告诉用户为什么值得买。

内容包括：

- 3到5个卖点图标
- 面料、手感、造型、工艺、尺寸
- 产品局部特写

### 第3张：材质与工艺细节

目标：提升品质感和信任感。

内容包括：

- 面料微距
- 刺绣细节
- 缝线细节
- 填充饱满度
- 安全工艺说明

### 第4张：尺寸与场景

目标：解决用户对大小和用途的疑问。

内容包括：

- 手持比例
- 桌面比例
- 包挂比例
- 沙发/床头/车内场景
- 尺寸标注

### 第5张：情绪价值/礼品场景

目标：强化购买理由。

内容包括：

- 送朋友、送恋人、送孩子、送自己
- 治愈陪伴感
- 节日礼物氛围
- 包装展示

### 第6张：规格售后与下单理由

目标：减少顾虑，推动下单。

内容包括：

- 尺寸、重量、材质、包装
- 清洗建议
- 发货说明
- 色差提醒
- 售后保障

## 毛绒玩具详情页重点卖点

优先挖掘以下卖点：

- 软糯手感
- 饱满填充
- 不易变形
- 亲肤短毛绒
- 精细刺绣五官
- 可爱表情
- 桌面陪伴
- 拍照出片
- 送礼体面
- 可挂包、车载、床头、办公桌
- 小众设计
- 情绪价值

## 图片提示词要求

每张图需要包含：

- 拍摄风格
- 背景场景
- 主体构图
- 光线
- 材质细节
- 镜头角度
- 商业电商氛围
- 文字区域预留

示例格式：

```text
高级商业摄影风格，淘宝详情页主视觉，白色/浅色高级背景，产品居中大特写，柔和棚拍灯光，主体清晰突出，毛绒材质细节真实，画面右侧预留标题文字区域，高清8K，电商广告质感。
```

## 输出格式模板

```markdown
# 电商详情页方案

## 1. 产品定位
## 2. 目标用户
## 3. 核心卖点
## 4. 主图5张方案
## 5. 详情页6屏方案
## 6. 每屏文案
## 7. AI图片提示词
## 8. 小红书/淘宝关键词
## 9. 转化率优化建议
```

## 注意事项

- 不要只写空泛高级感，要具体到每张图怎么拍、写什么字、突出什么卖点。
- 商品如涉及他人IP、明星、赛事、影视形象，应提醒避免直接使用受保护元素。
- 对竞品图片只做结构和视觉策略参考，不建议直接复刻。
- 详情页文案应避免绝对化广告词，如最强、第一、100%无风险等。
