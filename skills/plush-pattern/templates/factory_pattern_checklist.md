## 7. 修版建议

| 问题 | 修版方法 |
|---|---|
| 头太扁 | 加宽头顶中片或增加侧片弧度 |
| 脸不圆 | 增加脸颊片外弧 |
| 嘴不凸 | 增加嘴套高度和侧边省道 |
| 后脑塌 | 增加后脑片鼓量 |
| 身体瘦 | 增加侧身片宽度 |
| 脚站不稳 | 加大脚底片或加入颗粒配重 |
| 耳朵塌 | 增加内衬或缩短耳根 |
| 刺绣歪 | 重新定位到更平缓曲面 |
